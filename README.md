# OASIS PLACEMENT — Official Website

A modern, mobile-first single-page website for **OASIS PLACEMENT**, a recruitment agency in Silvassa (Dadra & Nagar Haveli) connecting top talent with leading industries.

## ✨ Highlights

- **100% Job Guarantee** badge & trust-first corporate blue + gold design
- **Hero** with live hiring cards, stats strip & animated ticker
- **Industries We Serve** — Manufacturing, Packaging, Textile, Pharma, Engineering, IT & Automobile
- **Fast Track Application** form (name, phone, industry, resume upload) with smart validation & success state
- **Contact** — Rahul Tiwary, both phone numbers, email, address & Google Maps link
- Mobile sticky action bar (**Call Now / Apply Now**) + floating WhatsApp button
- Smooth scroll-reveal animations, hover shine effects, fully responsive

## 🛠 Tech

- Single `index.html` file — zero build step
- [Tailwind CSS](https://tailwindcss.com) via CDN
- Vanilla JavaScript (no dependencies)

## 🚀 Run Locally

Just open `index.html` in any browser, or serve it:

```bash
npx serve .
```
